# О.К.О. — автономный ИИ-терминал выживания

Мобильное приложение для Android в ретро-стиле Windows 95, созданное для работы в условиях полного отсутствия связи и интернета.

## Основные возможности
* **Офлайн ИИ-сканер:** распознавание грибов, растений и объектов по камере с выводом процента уверенности.
* **Гайды по выживанию:** пошаговые инструкции по регионам и сезонам с живым поиском.
* **Офлайн-библиотека:** более 400 встроенных статей и справочных материалов.
* **Мини-карта:** определение координат по GPS, климатического пояса и списков местной флоры.

> **Важно:** Приложение носит исключительно справочный характер. Нейросеть может ошибаться — не употребляйте в пищу незнакомые грибы и растения без личной проверки.
